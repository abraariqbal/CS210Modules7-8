Summarize the project and what problem it was solving.
The project was to create a program  in C++ that tracked how often grocery store items are purchased by reading data from an input file. The goal of the program was to help the store analyze purchasing patterns. The program lets the user search for item frequencies, view of all item counts, and display a histogram.

What did you do particularly well?
I did well in organizing the program using a class and a map to store and access item frequencies. The menu system was simple and easy to use and all the options worked as expected.

Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
An area for improvement would be adding more input validation such as invalid menu choices or unexpected user input. I could also improve the efficiency by using refererences in loops. This would make the program more reliable and better at handling edge cases. 

Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
The most challenging part was understadning how to use a map to count item frequencies and how itemFrequency[item]++ works. I overcame it by breaking it down step by step and testing with small examples.

What skills from this project will be particularly transferable to other projects or course work?
Skills like working with file input/output, using maps, and organizing my code with classes will be very helpful in future projects. Also the abilitiy to break down the problem and go through it step by step is something I can use in my future coursework.

How did you make this program maintainable, readable, and adaptable?
I made this program readable and maintainable by seperating the functionality into different functions within a class and using clear naming conventions. This structure makes it easy to add new features in the future without affecting the entire program.
